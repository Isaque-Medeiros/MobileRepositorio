Nossa Visão

Por que o BSFM Existe?

A má nutrição e a falta de informação sobre alimentação saudável são desafios reais no Brasil. O BSFM nasceu como um projeto acadêmico com o objetivo de explorar como a tecnologia pode ajudar as pessoas a entenderem melhor sua alimentação.

Visão

Democratizar o acesso à informação nutricional de qualidade, combinando inteligência artificial com dados científicos para tornar o acompanhamento alimentar mais acessível a todos os brasileiros.

Missão

Desenvolver uma ferramenta funcional que permita aos usuários registrar, analisar e planejar sua alimentação de forma intuitiva, utilizando visão computacional para reconhecimento de alimentos.

Valores

Transparência, acessibilidade, inclusão (com módulo LIBRAS), embasamento científico e melhoria contínua. Acreditamos que tecnologia bem aplicada pode transformar hábitos.

Funcionalidades Implementadas

O que o BSFM já Oferece

Cada funcionalidade foi desenvolvida como parte do projeto acadêmico, com foco em resolver problemas reais de nutrição.

Analise por IA

Utilize a camera do seu celular para fotografar pratos e obter uma estimativa de calorias, proteinas, carboidratos e gorduras atraves de visao computacional (YOLOv10).

Implementado

Perfil Biometrico

Calcule sua Taxa Metabolica Basal (TMB) e Gasto Energetico Total (TDEE) com base em dados como peso, altura, idade e nivel de atividade.

Implementado

Plano Alimentar Semanal

Organize suas refeicoes da semana com cafe da manha, almoco, jantar e lanches. Visualize os macros de cada refeicao planejada.

Implementado

Metas e Evolucao

Acompanhe seu progresso com graficos de evolucao de peso e IMC. Defina metas personalizadas e visualize seu historico de medicoes.

Implementado

Controle de Agua

Registre seu consumo diario de agua com meta de 2L. Acompanhe o progresso semanal e receba lembretes para se manter hidratado.

Implementado

Acessibilidade LIBRAS

Modulo com conteudo em Lingua Brasileira de Sinais para garantir que a comunidade surda tenha acesso a informacao nutricional.

Onde Estamos

Status Atual do Projeto

O BSFM e um prototipo funcional desenvolvido como Projeto Integrador Multidisciplinar (PIM) do curso de Analise e Desenvolvimento de Sistemas. Abaixo, o resumo do estagio atual de cada componente.

Frontend Web

90%

HTML, Tailwind CSS, JavaScript. Interface responsiva com tema escuro/claro.

Backend API

85%

C# .NET com Entity Framework. Rotas REST para todas as funcionalidades.

IA (YOLOv10)

70%

Reconhecimento de alimentos com YOLOv10 + dados nutricionais USDA.

Banco de Dados

80%

PostgreSQL com todas as tabelas necessarias e relacionamentos.

Deploy

100%

Backend no Render, frontend estatico. CI/CD configurado.

Testes

40%

Testes funcionais manuais realizados. Testes automatizados em desenvolvimento.

Sobre o BSFM

O Brazilian System of Food Metric (BSFM) e um projeto academico desenvolvido como parte do PIM (Projeto Integrador Multidisciplinar) do curso de Analise e Desenvolvimento de Sistemas. Nosso objetivo e demonstrar a aplicacao pratica de conceitos de programacao, banco de dados, inteligencia artificial e engenharia de software na criacao de uma solucao para nutricao.

Aviso importante: As informacoes fornecidas pelo sistema sao estimativas baseadas em dados publicos (USDA) e nao substituem a consulta com um nutricionista ou medico profissional.
